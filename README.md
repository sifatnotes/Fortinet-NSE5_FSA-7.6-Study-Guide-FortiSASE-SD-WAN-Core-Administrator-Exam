## Exam Overview

The **Fortinet NSE 5 - FortiSASE and SD-WAN Core Administrator (NSE5_FSA-7.6)** exam evaluates your applied knowledge in configuring, deploying, running daily operations, and troubleshooting cloud-native FortiSASE and Secure SD-WAN infrastructure across hybrid enterprise environments.

| Parameter | Details |
| :--- | :--- |
| **Exam Code** | NSE5_FSA-7.6 / NSE5_SSE_AD-7.6 |
| **Certification Track** | Fortinet Certified Professional (FCP) - SASE / Network Security |
| **Target Firmware Version** | FortiSASE 7.6 / FortiOS 7.6 |
| **Exam Duration** | 70 Minutes |
| **Question Count** | 35–40 questions (Multiple Choice & Drag-and-Drop) |
| **Passing Score** | Pass / Fail (Reported via Pearson VUE) |
| **Delivery Mechanism** | Pearson VUE Test Centers & OnVUE Online Proctored |

## Who Should Take This Exam

This exam is designed for network and security professionals who:
- Oversee secure access for hybrid remote workforces using FortiSASE cloud points of presence (POPs).
- Manage decentralized SD-WAN setups, direct internet access (DIA) steering, and SLA-based routing on FortiGate firewalls.
- Integrate enterprise SD-WAN topologies with FortiSASE (SPA - Secure Private Access).
- Implement endpoint compliance enforcement, Web Filtering, Inline CASB, and DLP profiles across managed endpoints and cloud applications.
